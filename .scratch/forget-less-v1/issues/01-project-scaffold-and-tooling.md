# 01: Project scaffold and tooling

**What to build:** Set the Xcode project up the way the spec's "Project" section and `CODING_STANDARDS.md` describe, so every later ticket starts on a green build:
- iOS 18 and strict Swift 6 everywhere;
- empty `Domain` and `Data` local packages, wired to the app;
- Factory for DI;
- the SwiftLint build plugin;
- an en/uk String Catalog;
- `scripts/check.sh` passing.

The app still shows a placeholder screen. Nothing user-facing changes yet.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Deployment target is iOS 18. The app target and both packages use the Swift 6 language mode with complete strict concurrency, and packages also declare macOS 15 so `swift test` runs on the Mac.
- [x] The UITests target is deleted, along with its scheme entries.
- [x] The app's folders follow the layout in `CLAUDE.md` (`App/`, `Composition/`, `Features/`, `Shared/`, `Resources/`). The template's `ContentView` is replaced by a placeholder in `Features/`.
- [x] `Domain` (Foundation only) and `Data` (depends on Domain, SwiftData, FactoryKit) packages exist, each with a Swift Testing test target containing one real smoke test, and the app links both.
- [x] Factory is added. Data has a `DI/` registration for the `ModelContainer`, and the app has a `Composition/` extension ready for use cases.
- [x] The SwiftLint build plugin runs `ForgetLess/.swiftlint.yml` on the app target. A typed `Text("literal")` fails the build.
- [x] The String Catalog exists with at least one key carrying both `en` and `uk`, created with `scripts/xcstrings.py set`. `scripts/xcstrings.py check` passes.
- [x] The accent colour is the reference red, with light and dark variants in the asset catalog.
- [x] `build_sim` succeeds and `scripts/check.sh` ends with `check.sh: OK`.

## Comments

- 2026-10-25: Implemented on branch `docs/forget-less-v1-spec`. Verified: `build_sim` succeeds with no warnings; a temporary `Text("literal")` failed the build through the SwiftLint plugin; the app runs on the iPhone 16 Pro (iOS 18.5) simulator and shows the catalog's "Today"; `scripts/check.sh` ends with `check.sh: OK` (Domain 2 tests, Data 1); `test_sim` succeeds with no app tests yet.
- Decisions made while implementing:
  - Domain's smoke test is the Task name rule: `validatedTaskName(_:)` and `DomainError.emptyName`, built test-first. It sits in `Models/Entities/` until ticket 03 adds `TodoTask`; it can become a `TodoTask` member then.
  - The accent is Todoist red: `#DC4C3E` light, `#E5675B` dark.
  - Factory is 3.5.x (PillsTracker is on 2.5); the import and registration syntax are the same.
  - `SWIFT_EMIT_LOC_STRINGS = NO` in the app, so builds never extract strings into the hand-managed catalog.
  - `Shared/` holds only `.gitkeep` for now; its `Components/`, `Extensions/`, `Modifiers/` and `Preview/` subfolders are created with their first files. The `.gitkeep` files are excluded from target membership, since synchronized groups would copy them into the bundles.
  - There was no shared scheme to edit: the `ForgetLess` scheme is autogenerated, so removing the UITests target removed it from the scheme.
  - Building from the command line needs `-skipPackagePluginValidation` in MobileBuildMCP's `extraArgs`, or the SwiftLint plugin stops at Xcode's plugin trust check.
